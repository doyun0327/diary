■ 흐름
----------------------------------------------------------

  프론트
    └─ POST /api/ai/draw
         { diaryLine, title?, character? }

  백엔드
    ① 크레용 스타일 템플릿 + diaryLine (+ character) → prompt 조립
    ② stabilityai/stable-diffusion-3.5-large 호출
    ③ { imageBase64 } 반환  (scene/prompt는 선택)


■ 요청
----------------------------------------------------------

{
  "diaryLine": "오랜만에 수영장을 가서 수영을 했다. 힘들었지만 뿌듯했다.",
  "title": "수영",
  "character": "a young boy with black hair"
}


■ 프롬프트 조립
----------------------------------------------------------

크레용 스타일 prefix:
Children's crayon diary art style, wax crayon texture, handmade drawing on paper,
soft pastel colors, warm cozy atmosphere, imperfect childlike strokes,
cute and emotional storybook illustration, simple and heartwarming.

공통 suffix:
Scene: {diaryLine 또는 이를 바탕으로 만든 영문 장면}
Character look (brief): {character}   ← 있을 때만
exactly one child, two arms, two legs, no extra limbs, no text, no watermark, no photorealism

negative_prompt 예:
text, watermark, photorealistic, photo, 3d render, extra limbs, deformed hands,
ugly, nsfw, multiple people


■ 이미지 호출
----------------------------------------------------------

모델 ID 고정:
  stabilityai/stable-diffusion-3.5-large

호출처 예 (팀 인프라에 맞게 하나만):
  - Hugging Face Inference API
  - 자체 GPU 서버에 올린 SD3.5 Large
  - 호스팅 SD API

설정 예:
  ai:
    sd:
      model: stabilityai/stable-diffusion-3.5-large
      api-url: ${SD_API_URL}
      api-key: ${SD_API_KEY}
      width: 640
      height: 992

Gemini / Flux 설정·코드는 넣지 말 것.

provider 필드 불필요.


■ 의사코드
----------------------------------------------------------

draw(req):
  if blank(req.diaryLine): 400

  prompt = CRAYON_STYLE_PREFIX
         + "\nScene: " + req.diaryLine   // 또는 간단 영문화
         + (character ? "\nCharacter look (brief): " + character : "")
         + "\nexactly one child, ..."

  png = callSd35Large(prompt, negative)
  return { imageBase64: "data:image/png;base64," + png }
