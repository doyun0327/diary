==========================================================
백엔드 AI 그림 — 스타일 id + (선택) 참조 사진
(프론트는 POST /api/ai/draw 1번만 호출)
작성일: 2026-09-13 (kidSketch / referenceImage 추가)
==========================================================


■ 흐름
----------------------------------------------------------

  프론트
    └─ POST /api/ai/draw
         {
           diaryLine?, title?, character?,
           style: "kidSketch" | "oilPastel",
           stylePrompt?,          // kidSketch 시 프론트가 상세 프롬프트 전달
           referenceImage?        // data:image/jpeg;base64,... 첨부 사진
         }

  백엔드
    ① style / stylePrompt 로 화풍 템플릿 선택
    ② referenceImage 가 있으면 img2img / IP-Adapter / 비전 기반 장면 재현
       (없으면 diaryLine + character 텍스트만으로 생성 — 기존 경로)
    ③ { imageBase64 } 또는 job 큐 응답


■ 요청 예 (사진 첨부 + 일러스트)
----------------------------------------------------------

{
  "diaryLine": "수영장에서 놀았다",
  "style": "kidSketch",
  "stylePrompt": "Redraw the attached photo as if an elementary school child ...",
  "referenceImage": "data:image/jpeg;base64,...."
}

※ referenceImage 가 있으면 character 필드는 생략될 수 있음.
※ diaryLine 과 referenceImage 중 최소 하나는 있어야 함.


■ kidSketch 프롬프트 요지 (stylePrompt 우선, 없으면 서버 기본값)
----------------------------------------------------------

- 첨부 사진을 초등학생이 따라 그린 듯한 그림
- 네임펜으로 삐뚤빼뚤·불안정한 선, 겹침·지저분함 OK
- 머리카락은 굵은 선으로 깔끔하게
- 얼굴은 동그랗고 단순, 밝은 표정, 눈은 작은 점 두개
- 코·입은 최소 선, 3등신, 큰 머리·작은 몸, 막대 팔다리
- 색칠은 거의 없음 — 특징만 크레파스/색연필로 대충
- 흰 종이 손그림 낙서 / 디지털·웹툰·전문 일러스트 금지
- 의도적으로 완성도 낮게, 선 두껍게, 팔다리 그림체 통일


■ oilPastel
----------------------------------------------------------

기존 오일파스텔 템플릿 유지.
(영어동화책 storybook 스타일은 제거됨 — 구 클라이언트가 보내면 kidSketch 로 폴백 권장)


■ 응답
----------------------------------------------------------

동기: { "imageBase64": "data:image/png;base64,...." }
비동기: 202 { "jobId", "status": "queued" } → GET /api/ai/draw/{jobId}


■ curl (로컬 테스트)
----------------------------------------------------------

# 텍스트만 + kidSketch
curl -X POST http://localhost:8080/api/ai/draw ^
  -H "Content-Type: application/json" ^
  -H "Authorization: Bearer YOUR_JWT" ^
  -d "{\"diaryLine\":\"공원에서 강아지랑 놀았다\",\"style\":\"kidSketch\"}"

# 사진 첨부는 body에 referenceImage: "data:image/jpeg;base64,..." 포함
