----------------------------------------------------------
1. 요청 / 응답 스펙
----------------------------------------------------------

POST /api/ai/draw
Content-Type: application/json

요청 body 예시:
{
  "diaryLine": "오늘은 피자 파티를 했어요.",
  "title": "피자 파티",
  "character": "a young boy with black hair wearing a blue t-shirt and glasses"
}

필드 설명:
- diaryLine  (필수) 일기 첫 줄(한글). 장면의 원문
- title      (선택) 제목
- character  (선택) 고정 캐릭터 영어 설명. 없으면 일반 아이로 그려도 됨

성공 응답 예시:
{
  "scene": "A young boy with black hair and glasses sitting at a table eating pizza.",
  "imageBase64": "data:image/png;base64,...."
}

또는:
{
  "scene": "...",
  "imageUrl": "https://...."
}

실패 응답 예시 (4xx/5xx):
{
  "message": "장면 설명 생성에 실패했습니다"
}


----------------------------------------------------------
2. 백엔드가 해야 할 2단계 처리
----------------------------------------------------------

[1단계] LLM으로 장면 설명 생성 (영어 1문장)
  입력: diaryLine(한글) + character(영어, 선택)
  출력: 예) "Two children sitting at a table eating pizza."

[2단계] 이미지 생성
  입력: 1단계 scene + character + kids crayon 스타일
  출력: PNG → Base64


----------------------------------------------------------
3. Spring Boot 컨트롤러 예시
----------------------------------------------------------

package com.example.diary.controller;

import org.springframework.http.MediaType;
import org.springframework.web.bind.annotation.*;
import org.springframework.web.client.RestClient;

import java.net.URLEncoder;
import java.nio.charset.StandardCharsets;
import java.util.Base64;
import java.util.Map;

@RestController
@RequestMapping("/api/ai")
public class AiDrawController {

    private final RestClient restClient = RestClient.create();

    public record DrawRequest(
            String diaryLine,
            String title,
            String character
    ) {}

    @PostMapping("/draw")
    public Map<String, String> draw(@RequestBody DrawRequest req) {
        if (req.diaryLine() == null || req.diaryLine().isBlank()) {
            throw new IllegalArgumentException("diaryLine이 비어 있습니다");
        }

        String character = (req.character() == null || req.character().isBlank())
                ? "a child"
                : req.character().trim();

        String diaryLine = req.diaryLine().trim();

        // ---------- 1) LLM: 일기 장면을 영어로 (캐릭터는 맨 아래 보조) ----------
        // ※ diary를 프롬프트 맨 위에 두고, character는 짧게만
        String llmPrompt = """
                Korean diary (MOST IMPORTANT — convert THIS action and place into English):
                %s

                Rules:
                1) Output ONE English sentence about what happens in the diary.
                2) Action and location from the diary MUST be the main focus.
                3) Do NOT write a character portrait. Do NOT ignore the diary.
                4) Optionally add a SHORT look hint at the end: %s
                5) Exactly one child, two arms, two legs.
                6) Output ONLY the sentence. No quotes. No Korean. No explanation.

                Example:
                Diary: 오늘은 피자 파티를 했어요.
                Output: A child eating pizza at a party table with friends.
                """.formatted(diaryLine, character);

        String scene = restClient.get()
                .uri("https://text.pollinations.ai/" + URLEncoder.encode(llmPrompt, StandardCharsets.UTF_8))
                .retrieve()
                .body(String.class);

        if (scene == null || scene.isBlank()) {
            throw new IllegalStateException("장면 설명 생성에 실패했습니다");
        }
        scene = scene.trim().replaceAll("^[\"']+|[\"']+$", "");
        scene = scene.lines().map(String::trim).filter(s -> !s.isEmpty()).findFirst().orElse(scene);

        // Pollinations 등이 붙이는 해시/잡문자 제거
        // 예: "... hamburgere5de163d51c4c382 ..." → 해시 삭제
        scene = scene.replaceAll("(?i)[a-f0-9]{24,}", " ");
        scene = scene.replaceAll("\\s+", " ").trim();
        // 문장이 너무 길면 앞 220자만 (이미지 프롬프트 오염 방지)
        if (scene.length() > 220) {
            scene = scene.substring(0, 220).trim();
        }
        // 일기가 아예 없으면 최소한의 fallback
        if (scene.isBlank()) {
            scene = "A child in a diary scene: " + diaryLine;
        }

        System.out.println("[AI] cleaned scene=" + scene);

        // ---------- 2) Image: 한글 일기 원문을 반드시 앞에 넣음 ----------
        // ※ LLM scene이 캐릭터만 말해도, diaryLine이 이미지에 직접 들어가 장면을 강제
        String imagePrompt = String.join(", ",
                "children's crayon drawing",
                "MUST clearly show this diary event: " + diaryLine,
                "English scene: " + scene,
                "focus on the action and place from the diary",
                "not a standing character portrait",
                "brief look of the child: " + character,
                "exactly one child",
                "correct human anatomy, two arms, two legs",
                "no extra limbs",
                "simple cute doodle",
                "thick wobbly crayon lines",
                "bright primary colors",
                "hand-drawn by a kid",
                "no text",
                "no watermark",
                "no photorealism"
        );

        String imageUrl = "https://image.pollinations.ai/prompt/"
                + URLEncoder.encode(imagePrompt, StandardCharsets.UTF_8)
                + "?width=768&height=512&model=flux&nologo=true";

        // 디버깅용 로그 (서버 콘솔에서 diaryLine / scene 확인)
        System.out.println("[AI] diaryLine=" + diaryLine);
        System.out.println("[AI] character=" + character);
        System.out.println("[AI] scene=" + scene);
        System.out.println("[AI] imagePrompt=" + imagePrompt);

        byte[] imageBytes = restClient.get()
                .uri(imageUrl)
                .accept(MediaType.IMAGE_PNG, MediaType.IMAGE_JPEG, MediaType.ALL)
                .retrieve()
                .body(byte[].class);

        if (imageBytes == null || imageBytes.length == 0) {
            throw new IllegalStateException("이미지 생성에 실패했습니다");
        }

        String base64 = "data:image/png;base64," + Base64.getEncoder().encodeToString(imageBytes);
        return Map.of(
                "scene", scene,
                "imageBase64", base64
        );
    }
}

4. 예외 처리 (권장)
----------------------------------------------------------

@RestControllerAdvice
public class AiExceptionHandler {
    @ExceptionHandler(IllegalArgumentException.class)
    @ResponseStatus(HttpStatus.BAD_REQUEST)
    public Map<String, String> badRequest(IllegalArgumentException e) {
        return Map.of("message", e.getMessage());
    }

    @ExceptionHandler(Exception.class)
    @ResponseStatus(HttpStatus.INTERNAL_SERVER_ERROR)
    public Map<String, String> serverError(Exception e) {
        return Map.of("message", "AI 그림 생성 중 오류가 발생했습니다");
    }
}

8. 다리가 3개 / 몸이 이상할 때
----------------------------------------------------------
원인:
- 캐릭터 설명이 너무 길고, scene + imagePrompt에 이중으로 들어감
- "childlike proportions" 같은 표현이 해부학을 망가뜨림
- hex 색코드(#4dabf7)를 프롬프트에 넣으면 모델이 헷갈림

프론트 대응 (이미 적용됨):
- character 문자열을 외형만 짧게 (성별·머리·옷·액세서리 1개)
- 액세서리/자유설명 길이 제한

백엔드 필수 수정:
- imagePrompt에서 character를 길게 반복하지 말 것
- "childlike proportions" 삭제
- "exactly two arms and two legs", "no extra limbs" 추가


----------------------------------------------------------
9. 일기 내용이 안 나올 때 (캐릭터만 나옴)
----------------------------------------------------------
원인:
- LLM이 캐릭터 외형만 영어로 바꾸고 일기 행동을 무시
- imagePrompt에 diaryLine이 없고 scene만 있음

백엔드 필수 수정 (3절 예시 반영):
1) LLM 프롬프트에서 한글 diaryLine을 맨 위에 두기
2) imagePrompt 맨 앞에 반드시 넣기:
   "MUST clearly show this diary event: " + diaryLine
3) 캐릭터는 "brief look"로만 짧게

확인:
- 서버 로그의 [AI] diaryLine=... / scene=...
- 프론트에 "AI가 이해한 장면:" 이 뜨면 scene 확인 가능
- scene에 피자/공원 같은 일기 단어가 없으면 백엔드 프롬프트를 다시 확인

위 3절 예시 코드를 Spring Boot에 다시 반영한 뒤 서버를 재시작하세요.
