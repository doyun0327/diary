작성일: 2026-07-21

[ 목표 ]
- 프론트엔드(React + Vite, http://localhost:5173)와
  백엔드(Spring Boot, http://localhost:8080)를 연동한다.
- 연결 확인용 테스트 API: GET /api/test
  응답 예시:
    {
      "message": "프론트엔드 연결 성공",
      "status": "ok"
    }


----------------------------------------------------------
1. 프론트엔드에서 한 작업 (이 저장소)
----------------------------------------------------------

(1) Vite 개발 서버 프록시 설정  -  vite.config.ts
    - 브라우저에서 8080으로 직접 요청하면 CORS 문제가 생기므로,
      개발 중에는 /api 로 시작하는 요청을 Vite가 8080으로 대신 전달(proxy)하도록 설정.
    - 코드:
        server: {
          proxy: {
            '/api': {
              target: 'http://localhost:8080',
              changeOrigin: true,
            },
          },
        }
    - 즉 프론트는 항상 같은 출처(/api/...)로 부르고, 실제 전달은 Vite가 처리.

(2) 백엔드 호출 함수  -  src/api/testApi.ts
    - GET /api/test 를 호출하고 응답을 검증하는 함수 testBackendConnection() 작성.
    - HTTP 실패(응답 코드가 200번대가 아님) 시 에러를 던짐.
    - 응답의 status 값이 "ok" 가 아니면 에러를 던짐.
    - 응답 타입(TestApiResponse: message, status)을 정의해 타입 안전하게 사용.

(3) 앱 시작 시 자동 연결 테스트  -  src/main.tsx
    - 개발 모드(import.meta.env.DEV)일 때만 앱이 뜨면서 testBackendConnection() 실행.
    - 성공하면 콘솔에  [API] 프론트엔드 연결 성공  출력.
    - 실패하면 콘솔에  [API] 연결 테스트 실패  와 에러 출력.
    - 브라우저 개발자도구(F12) > Console 에서 연동 여부를 바로 확인 가능.


----------------------------------------------------------
2. 백엔드에서 해야 하는 작업 (Spring Boot 프로젝트 쪽)
   * 이 저장소에는 백엔드 코드가 없어 아직 반영 못 함 *
----------------------------------------------------------

(1) 테스트 컨트롤러
    @RestController
    public class TestController {

        @GetMapping("/api/test")
        public Map<String, String> test() {
            return Map.of(
                "message", "프론트엔드 연결 성공",
                "status", "ok"
            );
        }
    }

(2) CORS 허용 (8080 서버에서 설정해야 함)
    - Vite 프록시를 쓰면 개발 중에는 CORS가 필요 없지만,
      프론트에서 8080으로 직접 호출하는 경우를 대비해 설정 권장.
    - 예시 (WebMvcConfigurer):

    @Configuration
    public class CorsConfig implements WebMvcConfigurer {
        @Override
        public void addCorsMappings(CorsRegistry registry) {
            registry.addMapping("/api/**")
                    .allowedOrigins("http://localhost:5173")  // 개발 프론트 주소
                    .allowedMethods("GET", "POST", "PUT", "DELETE", "OPTIONS")
                    .allowedHeaders("*");
        }
    }

    - 주의: allowedOrigins("*") 는 나중에 로그인/인증을 붙일 때 위험.
      운영 배포 시에는 실제 서비스 도메인만 추가할 것.


----------------------------------------------------------
3. 연동 확인 방법
----------------------------------------------------------
1) 백엔드(Spring Boot) 8080 포트로 실행.
2) 프론트엔드 실행:  npm run dev  (5173 포트)
3-a) 브라우저에서 http://localhost:5173 접속 후
     개발자도구 Console 에  [API] 프론트엔드 연결 성공  이 뜨면 성공.
3-b) 또는 터미널에서 직접 확인:
     - 백엔드 직접:   curl http://localhost:8080/api/test
     - 프록시 경유:   curl http://localhost:5173/api/test
     둘 다 아래 JSON 이 나오면 정상:
       {"message":"프론트엔드 연결 성공","status":"ok"}
